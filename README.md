# ED-UP VR Controllers — v0.9 Stability+

**By Philou Cyberpunk**

Experimental community contribution to [ED Unofficial Patch](https://github.com/characterecho-sean/ed-unofficial-patch), targeting on-foot VR gameplay in Elite Dangerous: Odyssey, Windows 11 x64, Meta Quest 3 and OpenXR.

## Source archive

[Download ED-UP-VR-Controllers-v0.9-Stability.zip](https://github.com/user-attachments/files/35450529/ED-UP-VR-Controllers-v0.9-Stability.zip)

The source archive is attached to [upstream proposal #272](https://github.com/characterecho-sean/ed-unofficial-patch/issues/272). It includes C++17 code, OpenXR controller actions, keyboard/mouse input bridge, virtual hands, experimental stereo overlay and visual laser pointer, haptics, French configuration interface, integration scripts, automated tests and Windows validation documentation. The source files have not yet been imported into this repository.

## Status

Experimental prototype, not an installer or a stable VR release. Nine portable test suites were reported passing, including 20,000 simulated input samples. Full Windows compilation, upstream integration and physical Quest 3 testing remain outstanding. Independent 3D weapon/tool manipulation and direct terminal interactions are not implemented.

MIT-licensed source contribution. Technical feedback and collaboration are welcome. This is an unofficial contribution, not an official Frontier Developments project.
